CGraphApp

An interactive graph editor for system diagrams, kinetic mechanisms and neural networks. Runs in your browser; graphs are plain JSON files. I built this because I find that I think better in graph terms rather than text. The main idea is to use this tool to describe the systems I want to build, then translate the graph to Mermaid format and send it to an agent.
